# Política de segurança

## Versões mantidas

Somente o código da branch `main` recebe correções de segurança.

## Como relatar uma vulnerabilidade

Use o botão **Report a vulnerability** na aba **Security** do repositório para enviar o relato de forma privada. Não abra uma issue pública com detalhes exploráveis, credenciais, dados pessoais ou capturas contendo tokens.

Inclua no relato:

- área afetada e impacto esperado;
- passos mínimos para reproduzir sem acessar dados de terceiros;
- versão, commit ou URL em que o problema foi observado;
- sugestão de correção, quando houver.

Não realize testes destrutivos, indisponibilidade deliberada, engenharia social ou acesso a contas que não sejam suas.

## Segredos expostos

Se uma credencial for publicada, considere-a comprometida mesmo após apagar o arquivo. Revogue ou rotacione a chave primeiro e depois remova o valor de todo o histórico Git.
